# AI Stocks Made Simple - Mobile Preview

## Free beta hosting
The beginner app is designed to deploy on Streamlit Community Cloud from this GitHub repository.

Deployment settings:
- Repository: `Grzesiak33/Version-2-Stock-Investment-Model`
- Branch: `main` after the mobile-preview PR is merged
- Main file path: `beginner_app.py`
- Python dependencies: `requirements.txt`

## Phone use
After deployment, open the generated `*.streamlit.app` URL in Chrome on Android or Safari on iPhone.

Android: browser menu -> Add to Home screen / Install app (wording varies by browser).
iPhone: Share -> Add to Home Screen.

This creates a home-screen icon for the beta without requiring Google Play or the Apple App Store.

## Product boundary
This beta is educational research software. It displays model rankings and small-dollar math examples. It does not connect to brokerage accounts, place trades, or provide individualized investment recommendations.
